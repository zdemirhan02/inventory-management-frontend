# Mini Envanter Yönetim Sistemi

Bu proje, Spring Boot REST API servisi ile entegre çalışan stok ve kategori yönetim web arayüzüdür.

## Kullanılan Teknolojiler

- **Frontend:** React (Vite), Tailwind CSS
- **HTTP Client:** Axios
- **Routing:** React Router DOM
- **Bildirimler:** React Toastify
- **İkonlar:** React Icons
